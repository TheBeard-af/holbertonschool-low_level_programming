# Functions and Nested Loops

- **0-putchar.c:** Prints `_putchar`.
- **1-alphabet.c:** Prints the lowercase alphabet.
- **2-print_alphabet_x10.c:** Prints the lowercase alphabet ten times.
- **3-islower.c:** Checks if a character is lowercase.
- **4-isalpha.c:** Checks if a character is alphabetic.
- **5-sign.c:** Prints the sign of a number.
- **6-abs.c:** Computes the absolute value of an integer.
- **7-print_last_digit.c:** Prints the last digit of a number.
- **8-24_hours.c:** Prints every minute of a day.
- **9-times_table.c:** Prints the 9 times table.
- **10-add.c:** Adds two integers.
- **11-print_to_98.c:** Prints numbers from a given number to 98.
