# C - More functions, more nested loops

Holberton School project covering functions, nested loops, prototypes and scope.

## Files

- main.h: Function prototypes.
- 0-isupper.c: Checks uppercase characters.
- 1-isdigit.c: Checks numeric digits.
- 2-mul.c: Multiplies two integers.
- 3-print_numbers.c: Prints digits 0 to 9.
- 4-print_most_numbers.c: Prints digits excluding 2 and 4.
- 5-more_numbers.c: Prints numbers 0 to 14 ten times.
- 6-print_line.c: Draws a horizontal line.
- 7-print_diagonal.c: Draws a diagonal line.
- 8-print_square.c: Prints a square.
- 9-fizz_buzz.c: Prints FizzBuzz from 1 to 100.
- 10-print_triangle.c: Prints a right-aligned triangle.

## Compilation

Use gcc with -Wall -Werror -Wextra -pedantic -std=gnu89.
The evaluator supplies _putchar.c.
